# Проект мониторинга новостей МАИ

Это учебный проект для парсинга и мониторинга новостей с сайта МАИ. Он собирает публикации по нескольким рубрикам, сохраняет их в локальную базу данных SQLite и позволяет запускать периодическую проверку новостей.

## Что делает проект

Проект состоит из двух частей:

- `parser.py` — скачивает HTML страницы сайта МАИ и сохраняет результат в `page.html`.
- `mai_news_monitor/` — отдельный мониторинг новостей:
  - парсит страницы по категориям;
  - ищет новые публикации;
  - сохраняет их в SQLite;
  - удаляет старые записи по лимиту;
  - умеет выполнять одну проверку или работать по расписанию.

Поддерживаемые категории:
- `all`
- `education`
- `science`
- `campus`

## Установка

1. Склонируйте проект или откройте папку проекта.
2. Создайте виртуальное окружение:

```bash
python -m venv venv
```

3. Активируйте виртуальное окружение:

Для Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

Для Windows CMD:

```cmd
venv\Scripts\activate.bat
```

4. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

### 1. Сохранить HTML страницы сайта

```bash
python parser.py
```

После запуска файл `page.html` будет создан в корне проекта.

### 2. Показать статистику по сохранённым новостям

```bash
python mai_news_monitor\monitor.py --stats
```

### 3. Выполнить одну проверку новостей

```bash
python mai_news_monitor\monitor.py --once
```

### 4. Запустить постоянный мониторинг

```bash
python mai_news_monitor\monitor.py
```

По умолчанию используется интервал проверки из файла `mai_news_monitor/config.py` (сейчас `300` секунд).

### 5. Изменить интервал проверки

```bash
python mai_news_monitor\monitor.py --interval 600
```

Это запустит проверку каждые `600` секунд.

## Что хранится в базе данных

В SQLite таблица `news` хранит:
- идентификатор новости;
- заголовок;
- дату публикации;
- ссылку на новость;
- время добавления;
- категорию.

## Возможные особенности

- проект использует `requests` и `BeautifulSoup` для парсинга;
- данные сохраняются локально без сервера;
- монитор работает как скрипт, а не как веб-приложение;
- данные ограничены по количеству (`MAX_NEWS_COUNT`), чтобы база не разрасталась бесконечно.

## Полезные команды

```bash
python mai_news_monitor\monitor.py --once
python mai_news_monitor\monitor.py --stats
python mai_news_monitor\monitor.py --interval 120
```

## Примечание

Этот проект является учебным и работает с сайтом МАИ напрямую через HTTP-запросы. Для стабильной работы может потребоваться обновление селекторов HTML в случае изменения структуры страницы сайта.
